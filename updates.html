Game Catalog Ver. 1.0 Complete through September 2, 2026

Catalog, requests, schedules, records, and VODs

The Game Catalog now covers the complete viewer journey and the complete staff operation: discover a game, submit or test a request, confirm payment, publish the schedule, finish the stream, preserve the VOD, and manage records through final archive cleanup.

  1. Ver. 1.0Production release, backend consolidation, and live verification. Validated the complete 623-game catalog; moved every Game Request table, record, Edge Function, webhook, secret, schedule, and staff operation into the shared Polls | Appeals Center Supabase project; retired the old Game Request project; and passed the final live workflow test from submission through staff review, scheduling, completion, Discord delivery, records, archive, and owner deletion.
  2. Ver. 0.9.9Scheduled breaks and public availability. Added owner-selected cooldown end dates in Eastern Time, automatic reopening, a live countdown, a public front-page “⁅𝐓𝐡𝐲𝐓☣︎𝐱𝐢𝐜𝐆𝐚𝐦𝐞𝐫⁆ is taking a break” notice, and owner-only Open, Public Requests, and pink Cooldown indicators while preserving the separate automatic 14-day request cooldown.
  3. Ver. 0.9.8Protected game changes and flexible stream closeout. Limited viewers to one game change per request while preserving unlimited owner corrections and the original price bracket. Made Twitch the primary VOD, kept YouTube optional, and allowed either valid Twitch or YouTube VOD to complete a request.
  4. Ver. 0.9.7Owner production testing and real public schedule. Replaced fictional preview tools with owner-only $0 requests for owned or unlisted games. Test requests use the real approved-and-paid workflow without creating a StreamElements or PayPal transaction. The main catalog now always shows the public schedule, including the game title, system, Eastern date and time, request type, summary, and original release year—or a clear message when nothing is scheduled.
  5. Ver. 0.9.6Request records and archive cleanup. Added manual Move to Archive controls for verified staff, owner-only permanent deletion from Request Records, one owner-only Delete All Archived Requests action, protected database authorization, 30-day automatic archive transfer, and six-month retention cleanup.
  6. Ver. 0.9.5Discord delivery operations. Added private delivery health, recent success and failure history, retryable failed notifications, separate destination routing, and request-system logs limited to completed, denied, cancelled, and expired final outcomes.
  7. Ver. 0.9.4Completed Requests and VODs. Added staff closeout, completed Eastern date and time, secure automatic YouTube and Twitch VOD lookup with staff confirmation, permanent YouTube links, 60-day Twitch links, viewer completion details, public VOD cards, and dedicated Discord completion announcements.
  8. Ver. 0.9.3Scheduling and rescheduling. Added agreed Eastern schedule recording, future-date validation, required reschedule explanations, Discord schedule updates, public-safe schedule data, and staff editing until the scheduled time.
  9. Ver. 0.9.2Viewer and staff corrections. Added viewer replacement requests, staff approval or denial with explanations, same-price enforcement, staff game and platform corrections, permanent change history, status-page details, and Discord update notices.
  10. Ver. 0.9.1Automatic payment confirmation. Added StreamElements matching with unique TG references, secure payment deadlines, paid-state transitions, payment countdowns, regular-donation routing, and server-side confirmation.
  11. Ver. 0.9.0Request choices and protected pricing. Added Play Game, Speed Run Game, and 100% Completion choices with separate owned and unlisted prices enforced by the database.
  12. Ver. 0.8Organized Staff Control. Consolidated the private Home, Active Request, Request Records, Archive, and Admin areas with owner and verified moderator access, request service controls, global cooldown, staff alerts, and operational guidance.
  13. Ver. 0.7Availability and request lifecycle. Added the one-active-request slot, global service switch, 14-day community cooldown, pending review, awaiting payment, approved, completed, denied, cancelled, and expired states.
  14. Ver. 0.6Secure accounts and staff authorization. Connected Twitch OAuth, Supabase sessions, Row Level Security, automatic Twitch owner and moderator verification, revoked-access recovery, and protected server operations.
  15. Ver. 0.5Live viewer requests. Added owned-catalog and unlisted forms, viewer notes, Twitch-verified submissions, public request status, approval, required denial reasons, cancellation, and 48-hour payment expiration.

Poll Center Ver. 1.0 Complete through September 2, 2026

Live voting with protected poll control

Poll Center combines a public real-time voting experience with Twitch-verified creator controls, direct chat delivery, and a retained results archive.

  1. Ver. 1.0Supabase-only production release. Completed public voting and staff control on the shared Polls | Appeals Center project, migrated all API work away from Cloudflare, removed the retired Cloudflare worker and account, and connected the system to Central Command.
  2. Ver. 0.9Completed Poll Archive. Added searchable completed and cancelled records, result review, status filtering, pagination, and automatic deletion 30 days after a poll closes or is cancelled.
  3. Ver. 0.8Direct Twitch delivery. Supabase now sends voting links through Twitch as ThyToxicBot, protects OAuth tokens in Vault, records delivery state, and lets staff resend failed announcements without rolling back a live poll.
  4. Ver. 0.7Owner and moderator access. Added persistent Twitch-verified Supabase sessions, active poll_staff authorization, protected staff operations, and clear expired-session recovery.
  5. Ver. 0.6Three simultaneous polls. Added the active-poll switcher and enforced the same three-poll maximum in both the creator interface and database operation.
  6. Ver. 0.5Full poll lifecycle. Added create, edit, close, cancel, safe local testing, editable questions and answers, protected options that already contain votes, and final confirmation steps.
  7. Ver. 0.4Public voting states. Added one vote per browser per poll, timers, controlled result visibility, final winners, ties, cancelled results, no-vote results, connection failures, retry states, and mobile layouts.
  8. Ver. 0.3Flexible creator settings. Added two to ten answers, poll duration controls, result-display choices, preview, and the full creator form.
  9. Ver. 0.2Secure Supabase backend. Added isolated poll tables and operations, Row Level Security, Edge Functions, public read routes, staff-only writes, poll events, votes, Twitch connection state, and OAuth state storage.
  10. Ver. 0.1Poll Center foundation. Established the public voting page, protected creator design, demo mode, responsive visual system, and real-time result presentation.
