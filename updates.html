Game Catalog Ver. 1.0 Complete through September 2, 2026

Catalog, requests, schedules, and VODs

The Game Catalog now covers the full viewer journey: find a game, submit a request, follow staff and payment decisions, see the schedule, and return to the completed stream.

  1. Ver. 1.0Production release and backend consolidation. Validated the complete 623-game catalog; added secure automatic YouTube and Twitch VOD lookup with staff confirmation; moved all Game Request tables, records, Edge Functions, webhooks, secrets, and schedules into the shared Polls | Appeals Center Supabase project; cut the live site over; and retired the old Game Request project.
  2. Ver. 0.9Completed Requests & VODs. Added staff closeout, completed Eastern date and time, permanent YouTube links, 60-day Twitch links, viewer completion details, public VOD cards, and dedicated Discord announcements.
  3. Ver. 0.8Organized Staff Administration. Consolidated request service controls, global cooldown, schedule preview, Discord delivery health, recent records, and the dedicated archive; added privacy documentation and automatic pre-publish secret validation.
  4. Ver. 0.7Public and staff schedule previews. Added a privacy-safe public Next Viewer Request panel plus a fictional staff preview that expires automatically and changes no real requests, payments, schedules, cooldowns, or notifications.
  5. Ver. 0.6Viewer and staff corrections. Added viewer game-change requests, staff approval or denial with explanations, locked price and request types, permanent change history, status-page details, and Discord update notices.
  6. Ver. 0.5Payment and request controls. Added StreamElements payment matching with unique TG references, catalog and unlisted pricing tiers, paid-state labels, regular-donation Discord notices, the global service switch, and the 14-day community cooldown.
  7. Ver. 0.4Secure live request workflow. Connected Twitch sign-in, Supabase records, owner and moderator verification, approval, required denial reasons, cancellation, 48-hour awaiting-payment expiration, live viewer status, 30-day archive transfer, and six-month archive retention.
  8. Ver. 0.3Staff review and Discord routing. Added protected Staff Control, pending and awaiting-payment queues, scheduling and rescheduling announcements, request-system delivery logs, and safe Discord health tests.
  9. Ver. 0.2Catalog foundation. Built the multi-platform dashboard, search and sequential IDs, platform tabs, rotating showcases, responsive libraries, unified hover details, portrait artwork, unlisted requests, and expanded platform collections.
  10. Ver. 0.1Request prototype. Proved the original one-viewer-slot request, status, approval, payment-test, cancellation, and cooldown experience in local browser storage before the secure multi-user backend was introduced.

Poll Center Ver. 1.0 Complete through September 2, 2026

Live voting with protected poll control

Poll Center combines a public real-time voting experience with Twitch-verified creator controls, direct chat delivery, and a retained results archive.

  1. Ver. 1.0Supabase-only production release. Completed public voting and staff control on the shared Polls | Appeals Center project, migrated all API work away from Cloudflare, removed the retired Cloudflare worker and account, and connected the system to Central Command.
  2. Ver. 0.9Completed Poll Archive. Added searchable completed and cancelled records, result review, status filtering, pagination, and automatic deletion 30 days after a poll closes or is cancelled.
  3. Ver. 0.8Direct Twitch delivery. Supabase now sends voting links through Twitch as ThyToxicBot, protects OAuth tokens in Vault, records delivery state, and lets staff resend failed announcements without rolling back a live poll.
  4. Ver. 0.7Owner and moderator access. Added persistent Twitch-verified Supabase sessions, active poll_staff authorization, protected staff operations, and clear expired-session recovery.
  5. Ver. 0.6Three simultaneous polls. Added the active-poll switcher and enforced the same three-poll maximum in both the creator interface and database operation.
  6. Ver. 0.5Full poll lifecycle. Added create, edit, close, cancel, safe local testing, editable questions and answers, protected options that already contain votes, and final confirmation steps.
  7. Ver. 0.4Public voting states. Added one vote per browser per poll, timers, controlled result visibility, final winners, ties, cancelled results, no-vote results, connection failures, retry states, and mobile layouts.
  8. Ver. 0.3Flexible creator settings. Added two to ten answers, poll duration controls, result-display choices, preview, and the full creator form.
  9. Ver. 0.2Secure Supabase backend. Added isolated poll tables and operations, Row Level Security, Edge Functions, public read routes, staff-only writes, poll events, votes, Twitch connection state, and OAuth state storage.
  10. Ver. 0.1Poll Center foundation. Established the public voting page, protected creator design, demo mode, responsive visual system, and real-time result presentation.

Appeals Center Ver. 1.0 Complete through September 2, 2026

Complete appeal and archive workflow

Appeals Center supports private submissions, separate platform decisions, applicant updates, staff review, Discord delivery, and retained case records.

  1. Ver. 1.0Public production release. Completed submission through final archive, connected the shared Polls | Appeals Center Supabase backend, promoted Appeals Center to a live Central Command destination, and verified the end-to-end applicant and staff workflow.
  2. Ver. 0.9Private Discord delivery. Added secret-authenticated appeal alerts and final log delivery while limiting Discord content to case identifiers, status, event type, and the protected Staff Review link.
  3. Ver. 0.8Protected archive and retention. Added read-only closed-case records containing the full case history and automatic deletion after six months through a daily scheduled job.
  4. Ver. 0.7Safe test-ticket controls. Added clearly marked owner test tickets and permanent deletion only for those test records; real appeals never expose the delete control.
  5. Ver. 0.6Role-based Staff Review. Added Owner, Admin, and Moderator access; case assignments; private notes; evidence and recommendations; applicant updates; approval, denial, requests for information, and closure controls.
  6. Ver. 0.5Status, messages, and audit history. Added private applicant tracking, automatic refresh, case messages, decision reasons, staff notes, and a complete event log from opening through closure.
  7. Ver. 0.4Individual and Universal Appeals. Added one-platform submissions and linked multi-platform submissions that create a separate case and decision for each selected platform and moderation action.
  8. Ver. 0.3Verified account access. Connected Twitch OAuth as the primary sign-in with passwordless email as a backup for applicants and assigned staff.
  9. Ver. 0.2Secure case backend. Added submissions, cases, messages, logs, staff membership, notes, Row Level Security, database functions, and protected role checks in Supabase.
  10. Ver. 0.1Appeals Center foundation. Established the branded, responsive workflow for Discord, Twitch, YouTube, Kick, X / Twitter, and Instagram with clear rules and separate case expectations.
